## 🚀 HOW TO USE

### 1. Setup (One-Time)
```bash
# Install dependencies
pip install -r requirements.txt

# Start Docker services
./scripts/start_services.sh

# Download AI models (optional - for Phase 4)
./scripts/download_models.sh
```

### 2. Run End-to-End Tests
```bash
python tests/test_end_to_end.py
```

Expected output:
```
✓ Data pipeline test passed
✓ Agent system test passed
✓ Validation pipeline test passed
✓ Risk metrics test passed
✓ Ensemble sentiment test passed
✓ Correlation manager test passed
✓ Order manager test passed
✓ ALL TESTS PASSED
```

### 3. Run Backtests
```bash
# Backtest a strategy
python scripts/run_backtest.py --symbol EUR_USD --start 2023-01-01 --capital 10000

# Walk-forward optimization
python scripts/run_backtest.py --walk-forward --train-period 252 --test-period 63
```

### 4. Deploy to Paper Trading
```bash
# Dry run (no real trades)
python scripts/deploy.py --environment paper --dry-run

# Live paper trading
python scripts/deploy.py --environment paper
```

### 5. Go Live (After Validation)
```bash
# Start with 1% capital
python scripts/deploy.py --environment live
```
